# Contributing

Follow the [Shuyra contribution standard](https://github.com/shuyra-arche/vanllia/blob/main/CONTRIBUTING.md).
The root README describes the layout, build commands and source version releases.

Keep maintenance changes separate from ABI, runtime or ownership changes. Record
commands actually run and distinguish compilation from guest acceptance. Update
`Cargo.lock` when changing dependencies or the shared version. Preserve source
attribution and effective interface contracts.
